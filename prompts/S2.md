## 2 — S2.c, `make-inserter`, and `insert-if-short` defined through it

> Next unit: the higher-order inserter and the function the assignment asks for.
>
> `(make-inserter x len-ok?)` returns a function of one argument (a list) that
> inserts `x` at the front of every list, at every level of nesting, whose
> length satisfies `len-ok?`, where `len-ok?` takes one number.
>
> Two things decide whether this is correct:
>
> 1. **Lengths are measured on the original list, before any insertion.** So
>    measure the length first, rebuild the elements second, and decide whether
>    to prepend `x` last. If an insertion inside an element could change the
>    length that gets tested, it is wrong.
> 2. **`'()` is not a pair.** An element may be an atom or a list, and the empty
>    list is a list that must still be transformed — so the dispatch is
>    `(or (pair? item) (null? item))`, not `pair?` alone. Empty lists are not
>    special: `()` has length 0 and becomes `(x)` whenever `0 < n`, and the same
>    goes for an empty top-level list.
>
> Use `letrec` for the two mutually recursive helpers, and use `my-length` and
> `my-map` from the previous unit.
>
> Then define `(insert-if-short x lst n)` in terms of `make-inserter`, passing
> the "shorter than n" test as the predicate. The file must end up with exactly
> **one** definition of `insert-if-short`, this one — a second `define` of the
> same name at module level is an error in Racket, and S2.c requires only this
> version to remain.
>
> Remember the top-level list is treated like every other list, so it can
> receive `x` too.
